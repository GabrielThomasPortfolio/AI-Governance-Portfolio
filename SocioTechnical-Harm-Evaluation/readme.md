**Socio Technical Harm Evaluation**
This folder contains a detailed evaluation of harmful outputs generated by a general purpose help chatbot. The report includes:
•	Harm classification across physical, financial, privacy, coercion, and regulatory domains
•	Severity scoring (likelihood × impact)
•	Rationale for harm categorization
•	Patterns of failure (disguised intent, multimodal amplification, operational shortcuts)
•	Safe alternative behaviors the model should have produced
This evaluation forms the foundation for the risk register and regression test suite.
