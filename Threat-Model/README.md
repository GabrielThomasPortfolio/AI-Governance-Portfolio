**Governance Level Threat Model**

This folder contains the governance layer threat model for the general-purpose help chatbot.

The document includes:
* Threat surfaces (input, external knowledge, model behavior, output)
* Threat scenarios
* Business impact
* Regulatory exposure
* Governance layer mitigations
* Control requirements
* Residual risk

This threat model complements the risk register by providing a system level view of how harms can emerge.
